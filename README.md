# Mayank Kashyap — AI/ML Engineer Portfolio

## Run locally
1. Keep `index.html`, `style.css`, `script.js`, and `Mayank_Resume.pdf` in the same folder.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.

## Deploy free with GitHub Pages
1. Create a GitHub repository named `mayank-ai-ml-portfolio`.
2. Upload all files from this folder to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. The URL will appear in Settings → Pages.

## Before publishing
- Verify the LinkedIn URL and all profile links.
- Your uploaded portrait is included as `assets/profile.png` and displayed in the hero section. Replace it with another image at the same path if needed.
- For the wellbeing project, the GitHub link currently points to your GitHub profile because a project-specific repository URL was not provided in the resume.
- Add verified metrics only if you have the actual results from your model evaluation.
- Keep the resume PDF in the repository root so the Download CV button works.

## Files
- `index.html`: page content and sections
- `style.css`: dark futuristic responsive design
- `script.js`: mobile menu, current year, and reveal animations
- `Mayank_Resume.pdf`: downloadable resume
